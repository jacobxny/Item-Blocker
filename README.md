A client side mod with infinite customization that allows you to block pickups from certain items.

With Item Blocker, you can choose certain items you don't want to pick up, and those items won't be picked up untill you remove them from the menu.

<summary>How To Use?</summary>
Simply press K or your desired keybind, and enter the name/ID of an item in the text box

Preferably type item names using their IDs like this:

- minecraft:grass_block

But you can also enter vanilla items using their names, like this:

- Grass Block
- Grass_Block
- and any other orientation

*Note: this only works with vanilla items, To add modded items, see below.*

(All item names are converted to their IDs)

Additionally, this mod works with modded items.
To enter modded items, type the item's ID, like this:

- modname:itemname

**For example, if I wanted to add the research table item from my mod Intelligence, I would type intelligence:research_table.**

Some mods may use a different format but this is the usual format for most mods.

</details>

<details closed="">
<summary>How To Find an Item ID?</summary>
  You can find an Item ID in many ways.
  
  One way is by pressing F3 + H, and then hovering over the item in your inventory.
  
  In the tooltip there should be a small piece of text saying minecraft:itemname, **thats the Item ID.**
</details>

<details closed="">
<summary>What mode should I use?</summary>

**This mod has two different modes:**

- Client side mode - Items are immediately dropped when picked up, and are always dropped untill they are removed from the menu

- Server side mode - Items are not picked up at all, and stay on the ground, this mode requires the mod to be installed on the server to work

</details>


# Dependencies:

- Fabric API: [Fabric API](https://modrinth.com/mod/fabric-api)
