# Whats new in Item Blocker 1.6:

- Added search functionality to the blocked items screens (Blocked Items and Presets)
- Searching allows for more streamlined and easier access to blocking items more efficiently
### How searching works:
- Click the search button next to the text box and the screen will turn to "search mode"
- Search for an item in the text box either by using its name or id or item tag (#planks, #wool).
- The list will dynamically update based on your query
-----------------------------------------------------------------------------------------
- Gave music discs their proper song / disc name in the item widgets, this just allows people to see what discs are blocked
- Redesigned the buttons on the main blocked items screen to be in a row at the top.
### What each button does:
- Clear all button: 
  - Fully clears your blocked item list and leaves an empty list 
- Options button:
  - Takes you to the option screen to change different settings
- Presets button:
  - Takes you to the presets screen where you can edit and apply presets.
----------------------------------------------------------------------------------------
- Holding shift when applying a preset allows you to keep your current blocked items while applying your preset.
- Added an option in the config file where you can adjust how the item list's are ordered, either alphabetically or randomly
- Added a tutorial when entering the main screen for the first time.
### What the tutorial shows:
- The tutorial shows what most things do on the main screen
- It also highlights key info and details
- You can click or press any button to skip the tutorial 
- You can replay the tutorial any time by pressing the "?" button
